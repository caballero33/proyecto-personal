# 💻 Frontend - TriageDoc

Esta carpeta albergará la aplicación cliente en **React** que consumirá la API REST del backend siguiendo la arquitectura **API-First** vista en la **Clase 1**.

### Funcionalidad Planeada:
* Formulario interactivo de autoevaluación de síntomas para el paciente.
* Panel médico para ver la lista de pacientes clasificados por color de prioridad (Rojo, Naranja, Amarillo, Verde, Azul).
* Consumo asíncrono de los endpoints REST expuestos por `TriageDoc.API`.
